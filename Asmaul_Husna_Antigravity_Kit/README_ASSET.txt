File:

- reference/asmaul-husna-wheel-mockup.png : mockup UI digital, referensi visual utama.
- reference/original-hand-sketch.jpeg : sketsa awal pengguna, referensi komposisi roda 99 segmen.

Cara menggunakan:
1. Salin folder reference/ ke root repository proyek Antigravity.
2. Salin isi prompt atau file Markdown ke Google Antigravity.
3. Pastikan Antigravity membaca kedua gambar dari folder reference/.
4. Gunakan gambar hanya sebagai acuan visual. Jangan jadikan gambar sebagai background aplikasi final dan jangan menyalin angka/teks Arab dari gambar sebagai database.
